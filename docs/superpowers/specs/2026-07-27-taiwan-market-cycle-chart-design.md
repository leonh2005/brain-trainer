- 日期：2026-07-27
- 狀態：待 Steven 審核

- Port：5900（Flask 網頁）

## 一、目標

做一張**互動式圖表**，把台股加權指數的「市場週期」畫在同一張時間軸上、用不同顏色區分，並用一條線標出**當前月份**落在每個週期的哪個位置。

主角是**杜金龍（杜老師）對台股加權指數的艾略特波浪劃分**（**月線**尺度，跨年大浪才畫得下），其餘固定長度週期與經濟週期當輔助層疊上去。另提供**切換鈕可切到日線＋均線**，看主升段有沒有「沿 5MA 噴」的短線訊號。

> 註：K 線尺度釐清——「5MA」是**5 日均線**（畫在日線圖上的移動平均），不是「5 分 K」（5 分鐘一根）。杜金龍/楚狂人講的「沿 5MA 噴上去」指日線強勢主升段。杜金龍跨年大浪推算（目標 47,000）用月線；日線＋均線是另一個尺度的操作訊號。本圖兩者都做，用切換鈕分開。

### 演進脈絡（為什麼是這個設計）

Steven 原本的 `kelly-fibonacci`（port 5700）是「四大**經濟**週期倉位計算器」，但那不是他要的。經過釐清，他要的是：

1. 各週期趨勢畫在**同一張圖**、不同顏色
2. 能看到**當前月份**的位置
3. 主角是**市場週期**（不是經濟週期）——特別是**杜金龍的艾略特波浪**
4. 台股加權指數為底層真實對照
5. 經濟週期（基欽/朱格拉）退居淡色背景參考層

## 二、重要現實聲明（設計前提）

**杜金龍的波浪劃分是主觀判斷，且會隨行情更新。** 網路上找到的是散見於財經媒體的公開報導，不同時間的版本數字不一致：

- 較新版（鏡週刊 2026/5）：初升段 12,629→24,416，目前主升段，**目標 47,000**
- 較早版（聯合新聞網）：用 2001~2008 歷史大循環，2027/5 循環高點**看 34,600**

因此本專案的做法是：**把某個版本的杜金龍劇本手動寫進參數檔（JSON），圖上明確標註資料來源與日期**，而非自動抓取或宣稱「精準預測」。杜老師更新時，改 JSON 即可。這個「劇本會變」的特性，本身就用「可切換劇本版本」呈現。

## 三、架構

Flask 網頁 + Plotly.js 互動圖（沿用 Steven 既有工具的模式：Flask + port + LaunchAgent）。

選 Plotly 是因為它內建：圖例點選開關每條線、hover 顯示數值、可疊多條 trace、前端即時重繪——正好對應「滑桿調參數即時看圖」「圖例開關每條週期」的需求。

```
market-cycle-chart/
├── app.py                 # Flask：首頁、/api/chart-data、/api/taiex?timeframe=
├── taiex_data.py          # FinMind 抓加權指數月線+日線 + 均線計算 + 本地快取
├── wave_scripts.py        # 杜金龍波浪劇本（多版本 JSON）+ 載入/驗證
├── cycles.py              # 固定長度週期正弦波產生器（相位計算）
├── econ_cycles.py         # 淡色經濟週期背景層（基欽/朱格拉）
├── current_position.py    # 計算「當前月份」落在每條週期/波浪的位置
├── templates/index.html   # 單頁介面：Plotly 圖 + 圖例開關 + 參數滑桿
├── static/                # Plotly.js（本地）、前端互動 JS
├── data/                  # taiex 月線快取 json
├── tests/                 # pytest
├── requirements.txt
└── README.md
```

### 資料流

```
FinMind API ──→ taiex_data.py ──→ 快取 data/taiex_monthly.json
                                        │
杜金龍劇本 JSON ──→ wave_scripts.py     │
固定週期參數 ──→ cycles.py              ├──→ app.py /api/chart-data
經濟週期參數 ──→ econ_cycles.py         │         │

```

## 四、各層設計

### 4.1 底層：台股加權指數真實 K 線（taiex_data.py）

- 用 FinMind 抓加權指數（TAIEX）**月線與日線**收盤。
- **月線**：主圖，範圍預設 **2020-01 ~ 當前月**，向未來延伸到 **2028-12**（讓波浪目標與週期未來段可見）。
- **日線**：切換視圖用，範圍預設近 2 年；附**均線**（5MA、20MA、60MA）。
- 抓取失敗 → 回退本地快取；快取也無 → 明確回傳錯誤，前端顯示「資料載入失敗」，不靜默給空圖。
- 快取每日更新一次即可。

### 4.1b K 線尺度切換與均線

- 前端切換鈕：**月線（大浪劇本）／日線（均線訊號）**。
- 月線視圖：波浪劇本 + 三條市場週期 + 經濟背景 +（可選）長均線。
- 日線視圖：日 K + 5MA/20MA/60MA，用來看「是否沿 5MA 噴上去」的主升段訊號；此視圖不畫跨年大浪。
- 均線在 `taiex_data.py` 以收盤價滾動平均計算。

### 4.2 主層：杜金龍波浪劇本（wave_scripts.py）

以 JSON 定義「劇本版本」，每版含：來源、日期、各浪轉折點（年月＋點位）、目標價位線、回檔買點區間。

**預設劇本 v1（鏡週刊 2026/5，「這波多頭」）：**

| 標記 | 點位 | 說明 |
|------|------|------|
| 第1浪起（初升段起點） | 12,629 | |
| 第1浪頂 | 24,416 | 漲 11,787 點 |
| 基準高（2026/2/26） | 35,579 | |
| 第3浪目標 | 47,000 | 35,579 + 11,787 |
| 回檔買點 | 7%~11% 修正 / 0.382 回檔 → 約 36,000~38,000 | |

**歷史劇本 v0（聯合新聞網，2027/5 循環高點版）：** 大循環 89 或 104 個月；2001 年 3,411 起，2002/4 高 6,484，2008/11 低 3,955；2025/9/19 高 25,864，2025/4 低 17,306；2027/5 目標 ×2 → 34,600。列為可切換版本，示範「劇本會變」。

前端以折線連接各浪轉折點、標浪編號、水平虛線畫目標價與回檔買點區間。**每個劇本版本標註來源與日期。**

### 4.3 市場週期正弦波（cycles.py）

三條固定長度週期，各自產生正弦波：

| 週期 | 預設長度 | 預設谷底錨點 |
|------|----------|--------------|
| 台股多空大循環 | 48 個月（4 年） | 2022-10（近期大底） |
| 半導體/科技庫存循環 | 42 個月（3.5 年） | 2023-01 |
| 季節性/月份效應 | 12 個月 | 每年固定相位 |

- 每條週期：`長度` 與 `谷底錨點年月` 前端可用滑桿/輸入框微調，即時重繪。
- 正弦波振幅正規化，疊在指數圖上以次要 Y 軸呈現（避免壓過主圖）。
- 配色統一由 dataviz skill 的 categorical palette 指派：每條市場週期一個色相、色相分明、light/dark 皆可讀；經濟週期背景層用更淡的灰階。

> 註：多空 4 年與庫存 3.5 年長度相近，預設用**不同谷底錨點**錯開，避免兩條線完全重疊；前端可各自微調。

### 4.4 淡色經濟週期背景層（econ_cycles.py）

- 一~兩條淡色正弦波（基欽 ~40 個月、朱格拉 ~108 個月）當基本面參考。
- 預設**關閉**，圖例可開；顏色更淡、線更細，不搶主圖。

### 4.5 當前月份位置（current_position.py）

- 一條垂直線標「今天所在月份」。
- 計算並在側欄顯示：當前落在**杜金龍第幾浪**、距目標價與回檔買點多遠、每條週期正弦波當前處於**上升/頂部/下降/底部**哪一段（用相位角換算）。

### 4.6 互動介面（index.html）

- **月線／日線切換鈕**（切換主圖尺度）。
- Plotly 主圖：圖例點選開關每條線。
- 側欄：每條市場週期的長度＋谷底錨點滑桿；劇本版本下拉選單（v1 / v0）；日線視圖的均線開關（5/20/60MA）。
- Hover 顯示日期與數值。
- 深色主題（沿用 Steven 既有工具風格）。

## 五、錯誤處理

- FinMind 抓取：try/except + 逾時；失敗回退快取；皆無則前端明確報錯。
- 劇本 JSON：載入時驗證必要欄位（浪點位遞增合理性、日期格式），格式錯誤明確報錯，不畫壞圖。
- 參數輸入：長度 > 0、谷底錨點在合理年月範圍，前端 + 後端雙重驗證。

## 六、測試（pytest，目標 80%+）

- `cycles.py`：正弦波相位計算、給定錨點與長度時當前月份的相位正確。
- `wave_scripts.py`：劇本 JSON 載入與驗證（合法/非法各案例）。
- `current_position.py`：當前位置分類（上升/頂/降/底）邊界值。
- `taiex_data.py`：FinMind 失敗時回退快取（mock）；均線（5/20/60MA）計算正確。
- `app.py`：`/api/chart-data`、`/api/taiex` 回應結構（integration）。

## 七、部署

- Port **5900**，Flask `debug=False`（沿用教訓：debug=True 的 reloader 會佔 port 導致 LaunchAgent exit=256）。
- LaunchAgent `com.steven.market-cycle-chart`，開機自動啟動。
- 完成後 `curl http://localhost:5900/api/health` 驗證，並用 Playwright 開頁面確認圖表正常渲染。

## 八、範圍界線（YAGNI）

- **不做**自動抓取杜金龍最新發言／NLP 解析——劇本手動維護。
- **不做**自動艾略特波浪計數（主觀、不可靠）。
- **不做**即時盤中資料——月線每日更新一次足矣。
- **不做**倉位計算（那是 kelly-fibonacci 的事，本專案獨立）。
