# TRIZ AI 解題工具設計

## 背景

Steven 想要一個網頁工具，用 TRIZ（發明問題解決理論）系統性解決問題，並結合 AI 讓分析更聰明。研究了 GitHub 上的相關專案，決定以 [Antropocosmist/triz-engineering-solver](https://github.com/Antropocosmist/triz-engineering-solver)（MIT 授權）的資料集為基礎：39×39 矛盾矩陣、40 發明原理、39 個工程參數說明。

## 使用者與範圍

僅 Steven 本人使用，不需要多人協作、登入機制、後端伺服器。

## 架構

單一 HTML Artifact，純前端 SPA。矩陣資料（39 參數、40 原理、39×39 矩陣對照表）整理成 JS 常數內嵌在頁面裡，不額外請求任何外部 API 或伺服器。

AI 呼叫使用 Artifact 的 `sample` capability（`capabilities: {sample: {}}`），頁面直接呼叫 Claude 生成/解析文字，不需要自行管理 API 金鑰。

歷史紀錄使用瀏覽器 `localStorage`（單人使用，不需跨裝置同步，不用 `db` capability）。

## 元件

- **AI 分析分頁**：問題輸入框 + 分析按鈕
- **手動查表分頁**：39×39 矩陣的參數下拉選單，可獨立使用，也被 AI 分析分頁的「修正參數」功能共用
- **參數確認/結果顯示元件**：兩個分頁共用，顯示目前選定的兩個參數 + 對應發明原理清單 + （若有）AI 客製化建議
- **歷史紀錄面板**：列出 localStorage 裡的過往分析，可點回顧

## 資料流（AI 分析模式，兩段式 AI 呼叫）

1. 使用者在問題輸入框描述情境，按下「分析」
2. **第一次 AI 呼叫**（`sample.json`）：傳入使用者問題 + 39 個參數清單，Claude 回傳 `{worsening: 參數編號, improving: 參數編號, reasoning: 一句話說明}`
3. 用兩個參數編號查內嵌的矛盾矩陣，秒出對應發明原理編號（矩陣每格通常對應 1-4 個原理）
4. 畫面顯示 AI 判斷的參數 + 查表結果，使用者可透過下拉選單手動修正參數（修正後即時重新查表，不重呼叫 AI）
5. 使用者確認參數後按「生成建議」，觸發**第二次 AI 呼叫**：傳入問題情境 + 確認後的參數 + 查表原理內容，Claude 生成一段客製化建議文字
6. 分析完成後自動存一筆記錄到 localStorage：問題文字、參數、原理、AI 建議、時間戳

手動查表分頁則跳過步驟 1-2，使用者直接選參數，走步驟 3 起的流程（不觸發 AI，除非使用者主動要生成建議）。

## 錯誤處理

- AI 呼叫失敗/逾時（`sample` reject）：顯示錯誤訊息 + 重試按鈕，不卡在「分析中」狀態
- AI 回傳的參數編號不在 1-39 範圍：判定為異常，直接導向手動選擇參數，不強行套用
- localStorage 寫入失敗（無痕視窗等）：try/catch 包住，僅提示「本次分析未存入歷史」，不影響當次結果顯示
- 矛盾矩陣格子本身無對應原理（矩陣中存在的空格）：顯示「此矛盾組合暫無經典對應原理，AI 建議會直接根據問題脈絡生成」

## 測試方式

純前端 Artifact，用瀏覽器實際跑過幾個真實案例驗證三個核心流程（AI 兩段式呼叫、手動修正、歷史紀錄讀寫）是否正常。不寫自動化測試套件。

## 明確排除範圍（YAGNI）

- 不做多人協作、分享連結給他人使用
- 不做後端伺服器、不接自管 API 金鑰
- 不做跨裝置同步（僅 localStorage）
- 不做自動化測試套件
