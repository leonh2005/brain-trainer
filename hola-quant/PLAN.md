# Hola-Quant：個人 AI 量化交易系統

**目標**：以 HolaOS 為底層，整合現有工具，建立能持續監控、決策、回報的 AI 操盤助手。
**策略方向**：大優勢低頻（事件驅動、情緒分析），不與大型量化拼速度。
**本金規模**：訊號驗證通過後再決定（Phase 3 完成前不實盤）

## 決策記錄

| 日期 | 決策 | 原因 |
|------|------|------|
| 2026-05-02 | 採用 HolaOS 作為 Agent 底層 | 支援長週期、狀態持久化，適合持續監控場景 |
| 2026-05-02 | 策略方向：大優勢低頻 | 個人無法在速度/算力與大型量化競爭 |
| 2026-05-02 | 執行層最後才啟用 | 先驗證訊號品質，避免自動下單未成熟就損失 |
| 2026-05-02 | 標的：週交易量前 20（含 ETF，排除美債 ETF）| 流動性高、進出容易，ETF 波動相對可控 |
| 2026-05-02 | 本機單一 process 架構（asyncio）| HolaOS Agent + TG Bot + Shioaji 三合一，不跨機通訊 |
| 2026-05-02 | 測試本金訊號驗證後再決定 | Phase 1-3 先跑模擬，驗證訊號準確率達標才實盤 |
