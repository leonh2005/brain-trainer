三、三檔推薦

日常 · DeepSeek V4 Flash

deepseek-ai/DeepSeek-V4-Flash · $0.14 / $0.28 每百萬 token · 1M context

你已在用。改 UI、加卡片、修錯字、抓資料、查詢這類佔你工作量七成，用最便宜的跑，判斷失準再往上轉。同價帶沒有更強的替代品。

主力 coding · Claude Sonnet 5.5 (xhigh)

claude-sonnet-5-5 · $3 / $15 每百萬 token · 1M context

跨檔 debug、Flask 服務重構、agent 邏輯這類需要可靠 tool call 的任務。選它的理由是原生 /v1/messages pass-through：tool_use、prompt caching、extended thinking 全部原樣轉發，沒有翻譯層出錯的空間。而且 cache 命中時 input 只算 10%，實際帳單遠低於表價。

降本選項：GPT-6.1 Sol（52 分 / $0.72，CP 絕對冠軍），但要走 OpenAI 格式，ccr 得把 Anthropic tool_use 翻成 OpenAI tool_calls — 這是最容易出 bug 的一段。值得實測，不建議直接當預設。

火力 · Claude Opus 5.5 (high)

claude-opus-5-5 · $5 / $25 每百萬 token · 1M context

架構決策、頑固 bug 的根因、長鏈推理。關鍵在 effort 檔位：high 就有 54 分，只比 Sonnet 5.5 的極限 56 分少 2 分，成本卻是三分之一。推到 max 檔拿 58 分要多付 3.3 倍，不划算。
