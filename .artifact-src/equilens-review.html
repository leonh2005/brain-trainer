02 · 安全檢查

我實際掃描了原始碼

通過

  • 依賴極小：Nexus 只有 @anthropic-ai/sdk 加 6 個 transitive；手機版 Pocket 零依賴。供應鏈攻擊面比一般專案小一個量級。
  • 無遙測：全 repo 掃不到 analytics、Sentry、PostHog、beacon、gtag 任何一種。
  • 對外網域全部可辨識：TWSE、TPEx、FinMind、Fugle、Twelve Data、Alpha Vantage、OpenAI，加新聞源（鉅亨、MoneyDJ、CMoney、經濟日報）與 Firebase 推播。沒有不明主機。
  • server.mjs 的出站請求只指向 127.0.0.1 與 localhost；實際打外部 API 的程式集中在 lib/providers/。
  • 金鑰在 macOS 走 Keychain（security add-generic-password），值透過 stdin 傳入，不會出現在 ps 輸出；網頁端永遠讀不回金鑰。
  • 沒有 eval、new Function 或動態執行程式碼；唯一的 child_process 用在金鑰保管。
  • 服務只綁 127.0.0.1，寫入 API 有 CSRF token 與同源檢查。
  • 完全沒有下單功能 — 純研究與通知，符合你不自動下單的原則。

仍需注意

  • 專案不到一個月，48 star 還不足以構成社群檢驗；我做的只是靜態模式掃描，不是逐行審計。
  • 手機通知必須開 Cloudflare Tunnel 把本機服務暴露到公網（有密碼 + CSP + 限流），或改用原生 App 經 Firebase 中繼。
  • 如果你想完全不開遠端存取，通知只會出現在電腦瀏覽器，而且頁面必須開著。

04 · 那段建議裡的兩個矛盾

照著做會踩到的問題

「不啟用手機遠端存取」但又要手機通知

不啟用手機遠端存取，先只設定行情 API。

手機推播只有兩條路：開 Pocket + Cloudflare Tunnel，或裝它的原生 App 走 Firebase 中繼。兩者都要把服務曝露出去。不開就只剩電腦瀏覽器通知，而且分頁要一直開著。

「V 型反轉 A/B/C 階段通知」它做不到

EquiLens 適合你的 00631L 即時行情、5 分 K、VWAP、V 型反轉 A/B/C 階段通知需求。

從 README 到程式碼都沒有這個功能。這句推薦是錯的，很可能是把「有 VWAP 訊號」誤當成「有 V 型反轉偵測」。

05 · 跟你現有架構的關係

它是一套平行系統，不是接上去就好

  • 你的行情統一走 Shioaji gateway（5455，獨佔連線）。EquiLens 走 Fugle／FinMind，是另一套資料源與金鑰。
  • 你的推播是 Telegram（10 多個服務共用）。EquiLens 是 Web Push，要另外維護 Tunnel 或 App。
  • 你已經有 28 個以上 LaunchAgent 在跑。多一個 Node 22 服務就多一份升級與故障面。
  • 反過來說：EquiLens 不碰 Shioaji 連線，不會跟你現有的 gateway 搶資源，這是唯一的架構優點。
06 · 建議

三條路，我傾向第一條

A · 不裝，在 Shioaji 體系自建 推薦

用你已有的 gateway + Telegram，寫一支 V 型反轉階段判定器。單一標的、單一策略，大約 200～300 行 Python。

  • 完全對準需求：A／B／C 三階段由你定義，不受別人框架限制
  • 行情源一元化，不新增 Fugle 金鑰與額度管理
  • 通知走既有 Telegram，不用開任何對外通道
  • 缺點：看盤視覺化要自己做（可掛進 command-center 5950）

B · 裝 EquiLens 當看盤台，V 型反轉另外自建

接受它的熱浪圖、盤中雷達、走勢視窗，但把 V 型反轉做成獨立腳本走 Shioaji + Telegram。

  • 省下看盤 UI 的工
  • 代價：兩套行情源、多一個 Node 服務、手機通知要開 Tunnel

C · Fork 下來改，把 V 型反轉加進去

在 lib/ 新增一個 V 型模組並掛進雷達。MIT 授權允許。

  • 功能整合在單一 UI
  • 代價最大：改別人的 AI 生成專案，上游每次更新都要 merge；你沒有 Node 生態的既有基礎
07 · 一個需要你確認的定義

「V 型反轉 A/B/C 階段」你指的是什麼？

技術分析裡沒有標準的 A／B／C 分段。常見理解是：A 段為左側急跌，B 段為底部盤整或假跌破，C 段為右側放量站回頸線／VWAP。但你的版本可能來自特定書籍或影片，定義會直接決定門檻值與通知時機。

如果走 A 或 B 路線，我需要你先給出這三段各自的判定條件，我才能把門檻寫成可調參數，而不是自己猜一套。
