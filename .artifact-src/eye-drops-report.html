自己看

四步判斷任何一款眼藥水

  1. 翻到「有効成分」欄，找這三個字：テトラヒドロゾリン、ナファゾリン、フェニレフリン。任何一個出現就是血管收縮劑。
  2. 看「効能・効果」：出現「結膜充血」幾乎等於有血管收縮劑——這是它唯一能宣稱的效果。
  3. 看類固醇：成分名結尾是 ゾロン、メタゾン、コルチゾン 就是類固醇。日本 OTC 不會有，台灣成藥也不該有。
  4. 看清涼感：LION 標 1–7，樂敦標 ★ 數。追「不涼」就找 0 或 ☆☆☆☆☆。
警語

青光眼族群的三件事

  • 血管收縮劑要避開。它作用在結膜血管，對眼壓沒有治療效果，卻可能讓房水循環更不穩定。日本包裝的「相談すること」欄位明列「緑内障」為使用前應諮詢的對象——這批被排除的六款全都印了這行。
  • 反彈性充血。連續點超過一週，停用後紅眼會反彈得更嚴重，很多人因此越點越依賴。
  • 防腐劑。多支裝幾乎都含 benzalkonium chloride，長期高頻使用對角膜上皮有累積傷害。若要天天點，單支裝（無防腐劑）的人工淚液是比較安全的底。
