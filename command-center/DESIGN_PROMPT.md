# Claude Design 操作指引（Steven 用）

## 步驟

1. 開 https://claude.ai/design
2. 選一個 dashboard 類 template（或 portal type）
3. 貼下面的 prompt（可加一張你喜歡的儀表板截圖，例如市場恐慌儀表板的畫面）
4. 它會問問題 → 照你的喜好回答（繁體中文、深色）
5. 出第一版後不滿意就直接跟它說要改哪裡
6. 定稿後：點「＋」→ Link Local Code → 選 `~/CCProject/command-center` 資料夾 → 跟它說「根據這個資料夾的 README.md 把儀表板改成用真實的區塊與資料欄位」
7. 右上角 Share → 下載 zip → 把 zip 檔丟到 `~/CCProject/command-center/` 裡，跟我說一聲即可

## 設計 Prompt（直接複製）

```
嗨 Claude，我想打造一個個人 AI 指揮中心儀表板，繁體中文介面、深色主題。

這是我所有自動化服務的統一入口，需要五個區塊：

1. 今日訊號牆（主角，佔最大版面）：台股當沖候選、隔日沖候選、盤中主力訊號、
   均線警報、籌碼異動、新聞情緒多空比、市場恐慌指標。每個訊號一張卡片，
   顯示更新時間，點擊展開細節。

2. 服務狀態列：20+ 個服務的健康燈號（綠/紅）、排程任務最後執行時間，
   可以做成頂部橫條或收合面板。

3. Skill 按鈕區：五個一鍵動作按鈕（重跑選股、更新籌碼、查個股等），
   按下後顯示執行中狀態與結果。查個股按鈕要有輸入框。

4. AI 聊天：常駐右側欄（手機上可收合），逐字串流顯示回覆，
   每輪對話顯示 token 用量。

5. 投組與生活區：投資組合現況卡片、寵物兔今日照護狀態、個人技能樹進度，
   放在頁面下方。

風格：專業金融終端感、深色底、資料密度高但不擁擠、漲用紅色跌用綠色（台股習慣）。
請先問我你需要確認的問題。
```
